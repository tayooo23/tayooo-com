mac lookup.

MACアドレスから、ベンダー（製造元）を検索する。

INPUT — 入力

MACアドレスの形式が正しくありません（16進数で入力してください）
区切りは「:」「-」「.」でも、区切りなしでもOK。先頭3オクテット（プレフィックス）だけでも検索できます。

VENDOR — ベンダー情報

VENDOR
MACアドレスを入力すると表示されます

データ出典：IEEE OUIレジストリ（MA-L／MA-S、2026-11-05取得時点）。ベンダーの住所は掲載していません。

ADDRESS — アドレスの情報
